### ⚠️ তিন রোল একসাথে টেস্ট করার নিয়ম

লগইন টোকেন ব্রাউজারের `localStorage`-এ থাকে, আর **একই ব্রাউজারের সব ট্যাব
একই `localStorage` শেয়ার করে**। তাই সাধারণ তিনটা ট্যাবে তিন রোলে লগইন করলে
শেষেরটা আগের দুইটাকে ওভাররাইট করবে — অ্যাডমিন ট্যাব রিফ্রেশ করলে দেখবেন
আপনি পেশেন্ট হয়ে গেছেন।

**সঠিক উপায় — তিনটা আলাদা ব্রাউজার কনটেক্সট:**

| রোল | কোথায় খুলবেন |
|---|---|
| ADMIN | সাধারণ Chrome উইন্ডো |
| DOCTOR | Chrome ইনকগনিটো উইন্ডো (`Ctrl+Shift+N`) |
| PATIENT | Firefox / Edge, অথবা Chrome-এর দ্বিতীয় প্রোফাইল |

ইনকগনিটোর দুইটা উইন্ডোও একে অপরের সাথে স্টোরেজ শেয়ার করে — তাই আলাদা
ব্রাউজার বা আলাদা প্রোফাইল লাগবেই।

> প্রতিবার কোড টানার পর প্রথম লোডে **`Ctrl+Shift+R`** (হার্ড রিফ্রেশ) দিন।
> সার্ভিস ওয়ার্কার পুরোনো জাভাস্ক্রিপ্ট ক্যাশ করে রাখে।

## ৩. সমস্যা হলে

| সমস্যা | সমাধান |
|---|---|
| পেজ খালি / পুরোনো আচরণ | `Ctrl+Shift+R` হার্ড রিফ্রেশ |
| এক ট্যাবে লগইন করলে আরেকটা লগআউট | আলাদা ব্রাউজার/প্রোফাইল ব্যবহার করুন (উপরে দেখুন) |
| ত্বক বা এক্স-রে পেজে "মডেল নেই" | `python ml\prepare_all.py --with-skin` চালান |
| হাসপাতাল তালিকা খালি | `python scripts\seed_database.py` চালান |
| ম্যাপে পিন নেই | লোকেশন অনুমতি দিন, নয়তো ঢাকা ডিফল্ট |
| CORS ত্রুটি | ফ্রন্টএন্ড `localhost`-এ চলছে কিনা দেখুন, `127.0.0.1` নয় |
